# Week2Day1-Prompt-assignment---1week-Veg-Meal-plan
An RTCFR-driven prompt engineering blueprint that builds a macro-precise, 1500 kcal South Indian weight-loss plan. It uses Role (Dietitian), Task (7-day plan), Context (Allergen filters/Tamil palate), Few-Shots (Portion examples), and Response (Table layout) to show how basic prompts upgrade into CoT, ReAct, and Multi-Agent logic.
